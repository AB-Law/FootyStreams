## How it was verified

- `uv run check` green on every commit (pre-commit hook). `uv run check --tier pr` green at the end of the milestone (coverage 96%, `verify/` and `sim/rng.py`, `sim/mathx.py` at 100%).
- Fuzz: 8 generated setups (every built-in formation) in the fast tier, 200 in the slow tier (`pytest -m slow tests/unit/sim/test_totality.py`, 200 passed in 85 s): every log satisfies `verify_match`.
- Statistical (slow tier, `pytest -m statistical`): stronger sides win more; goals/shots/conversion in loose bands.
- Determinism: same inputs give byte-identical NDJSON in-process and across processes under different `PYTHONHASHSEED`; three pinned goldens.
- Command: `uv run sim --demo --seed 7` prints a play-by-play of key events and a statistics table.

## Deviations from the design

1. **M1 events are slimmer than 03-events.md.** The sim emits the M1 shapes only; no `kind`/`outcome` enrichment, no preamble, no frame payload, no `xg` on `goal`. Nothing in M1 was changed. (M7 will have to add what it needs; see M7 report.)
2. **`SimRng` is not a wrapper of `random.Random`** (banned import); own xoshiro256** (ADR 0005).
3. **Digest** uses `model_dump_json()` lines, not sorted canonical JSON (speed); documented in `events/digest.py` and ADR 0006 (proposed, needs the owner's sign-off).
4. **Referee** is not in `MatchSetup` (only `referee_id`); the referee model arrives as an optional argument in M5.
5. **Formations** are built into `sim/formations.py` (no YAML loader yet); the role catalogue is optional and unused by M4.
6. **No Protocol seams** for sim components yet (single implementation each; `model_profile` is recorded only).
7. **Position cadence** is 4 s of match time (as designed) but the carrier acts every moment; players do not move during a pass.
8. **Out-of-play restarts** give the ball to the nearest opponent with no restart event (M5 adds throw-ins, goal kicks, corners). Keeper "held" saves put the keeper on the ball without a distribution event.
9. **Changelog policy quirk**: any file under `tests/golden/` counts as a golden change, so the golden case list lives in `tests/factories/golden_cases.py`.
10. **M1 test edit**: `test_versions__initial_constants` pinned the literal versions; it now checks the semver shape (needed for every bump).
