## How verified

- `uv run check` green on every commit; `uv run check --tier pr` green at the tip.
- Slow tier (`pytest -m slow`): 250 generated matches with every formation and strength mix pass `verify_match` and show injuries, changes and tactical changes at plausible rates (`tests/statistical/test_m6_rules.py`); metamorphic tests (`test_m6_metamorphic.py`): a loud home crowd lifts the home goal difference (scale 3 against 0, 400 matches each), heavy rain cuts long balls attempted by at least 8%, heat leaves players more exhausted at the end, trailing sides shoot more than leading ones after 60 minutes. The whole slow tier passes (213 tests, about 18 minutes in this container), including the M4 strength sweeps, the M5 sweeps and the 200-setup fuzz.
- Unit tests for each module; a manager who never acts leaves the log byte-identical (isolated streams); exhaustion never falls inside a half with injuries and the manager on.
- Verify catalogue: M06, M08 added; M07 now covers substituted and injured-off players; M11 men counts include unreplaced injuries; each has a crafted-violation test. M09 (exhaustion) is an engine-level test because events carry no fitness data.

## Deviations from the design

1. **Home advantage** uses a mean of atmosphere, proximity and passion (times 2, times crowd weight) rather than a product, and only the crowd channel plus the M5 referee tilt; the design's other channels (travel, familiarity) are absent. Defaults: crowd lift 0.12, away pressure 0.07.
2. **Injury types** are a built-in table, not `injury_types.yaml` (`data/` is out of this track's scope). The true diagnosis stays in `MatchState.injury_log`; the M7 summary needs a schema addition to carry it.
3. **Knocks** only cost stoppage time; the design's temporary performance loss is not modelled.
4. **AI manager** has five plans (fresh legs, chase, protect, dismissal reaction, yellow risk). No formation changes, opponent-threat response or half-time talk; the assessment noise comes from `tactical_knowledge` alone (the sheet has no `judging_ability`). Changes happen at the next stoppage the engine detects (a foul, throw-in, goal, ...), and half-time changes are logged just before the `halftime` event so the clock stays in the first half.
5. **Substitute fit**: a replacement must have at least `min_fit` (30) competence at the leaver's position; the newcomer plays the leaver's slot and role with `Duty.SUPPORT`.
6. **Window detection in `verify`** (M08) cannot read the config, so it groups changes within 60 s as one stoppage and exempts injury changes and first-half changes from minute 45 on: it never reports more windows than the engine used.
7. **Positioning order fix** (not in the design): both teams now plan from the same positions. It removed a measurable away edge that predates M6 (M4 and M5 outputs had it). It changes output for every seed, covered by the 0.3.0 bump.
8. **Changes a match** are limited by the factory bench (two outfielders and a goalkeeper a side), so the 4.2 a side target cannot be met in demo matches.
