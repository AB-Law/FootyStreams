## RoleCatalog contract (M2 `roles.yaml` must conform)

Pure in-memory catalog passed into `ratings.*`. YAML loading arrives in M2; tests ship a minimal in-code catalog of this shape.

```text
RoleCatalog
  roles: Mapping[RoleId, RoleDefinition]   # non-empty

RoleDefinition
  role_id: RoleId
  position: Position                       # used for position_competence scaling
  duties: Mapping[Duty, RoleDutySpec]      # non-empty

RoleDutySpec
  attr_weights: Mapping[str, float]        # non-empty; non-negative; sum > 0
                                           # (normalized to sum 1 inside the CA formula)
  offset_x: Unit = 0.0                     # spatial hint for sim (unused in M1 ratings)
  offset_y: Unit = 0.0
  utility_biases: Mapping[str, float] = {} # decision biases for sim (unused in M1 ratings)
```

**CA formula** (`compute_current_ability`): for each role+duty, competence-scaled weighted mean of listed attrs (weights normalized to sum 1); `ability_current` = max over catalog roles, clamped to AbilityScore 1–100.

**team_rating**: for each starter in the XI, rate the **assigned** `role`+`duty` from the catalog; fall back to that player's best-fit CA only if the assignment is missing. Mean over 11 → 0–100.

**market_value**: pure `f(CA, PA, age, reputation, contract_years_left)`. Property tests: monotonicity for CA/PA/rep (others fixed); younger high-PA premium as a metamorphic property (not a global age monotonic claim).
